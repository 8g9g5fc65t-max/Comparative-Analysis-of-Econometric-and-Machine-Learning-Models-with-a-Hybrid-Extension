## Data pipeline

```bash
python src/data_pipeline.py
```

Downloads daily OHLCV for the S&P 500 index (`^GSPC`, 2011–present) from
Yahoo Finance via `yfinance`, and produces:

- `data/raw/gspc_raw.csv` — the untouched pull (Date, Open, High, Low,
  Close, Adj Close, Volume).
- `data/processed/gspc_processed.csv` — the same data after cleaning
  (duplicate/weekend-row checks, NYSE trading-calendar gap check), with
  `log_return` (computed on Adj Close) and three boolean flag columns
  (`flag_missing_value`, `flag_zero_volume`, `flag_outlier_return`) —
  suspicious rows are flagged, never silently dropped.
- `docs/data_provenance.md` — source, download date, actual period
  returned, cleaning rules applied, and the dividend-adjustment caveat
  (`^GSPC` is a price index, not total return). Regenerated by the script
  on every run — don't hand-edit it.

Re-running the script re-downloads the current Yahoo Finance history and
overwrites all three outputs.
